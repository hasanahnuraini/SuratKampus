# Panduan Penggunaan Web SuratKampus

## 1. Registrasi Akun Mahasiswa
Pengguna yang belum memiliki akun dapat melakukan registrasi melalui halaman daftar.
Langkah-langkah:
1. Buka halaman utama SuratKampus.
2. Pilih menu **Daftar**.
3. Masukkan nama, email, NIM, program studi, dan kata sandi.
4. Pastikan seluruh data telah diisi dengan benar.
5. Klik tombol **Daftar**.
6. Setelah berhasil, pengguna dapat masuk menggunakan akun yang telah dibuat.

## 2. Login
Pengguna dapat masuk ke sistem menggunakan email dan kata sandi.
Langkah-langkah:
1. Buka halaman **Login**.
2. Masukkan email.
3. Masukkan kata sandi.
4. Klik tombol **Masuk**.
5. Sistem akan mengarahkan pengguna sesuai dengan role akun.
Mahasiswa akan diarahkan ke halaman mahasiswa, sedangkan admin atau petugas akan diarahkan ke halaman pengelolaan pengajuan.

## 3. Mengajukan Surat
Mahasiswa dapat mengajukan surat administrasi melalui sistem.
Langkah-langkah:
1. Login sebagai mahasiswa.
2. Masuk ke menu **Pengajuan Surat**.
3. Pilih jenis surat yang dibutuhkan.
4. Isi data pengajuan sesuai dengan kebutuhan surat.
5. Periksa kembali data yang telah dimasukkan.
6. Klik tombol untuk mengirim pengajuan.
7. Sistem menyimpan pengajuan dan memberikan kode pengajuan.
Jenis surat yang tersedia meliputi surat observasi mata kuliah/mini riset, magang mandiri, PKLI, dan observasi skripsi.

## 4. Melihat Status Pengajuan
Mahasiswa dapat memantau perkembangan pengajuan surat melalui dashboard.
Status pengajuan dapat berupa:
- **Menunggu**: pengajuan menunggu pemeriksaan admin/petugas.
- **Diproses**: pengajuan sedang diperiksa atau memerlukan perbaikan.
- **Selesai**: pengajuan telah selesai dan surat dapat diunduh.
- **Ditolak**: pengajuan tidak disetujui.

## 5. Memperbaiki Pengajuan
Jika admin/petugas meminta perbaikan, mahasiswa dapat memperbaiki data pengajuan.
Langkah-langkah:
1. Login sebagai mahasiswa.
2. Buka dashboard.
3. Pilih pengajuan dengan status **Diproses**.
4. Baca catatan/perbaikan dari admin.
5. Klik **Edit / Lengkapi Data**.
6. Perbaiki data sesuai catatan.
7. Simpan perubahan.
8. Pengajuan akan kembali berstatus **Menunggu** untuk diperiksa kembali.

## 6. Pengelolaan Pengajuan oleh Admin/Petugas
Admin atau petugas dapat mengelola pengajuan surat mahasiswa.
Langkah-langkah:
1. Login menggunakan akun admin atau petugas.
2. Buka halaman pengelolaan pengajuan.
3. Lihat daftar pengajuan mahasiswa.
4. Periksa data pengajuan.
5. Tambahkan catatan jika terdapat data yang perlu diperbaiki.
6. Ubah status pengajuan sesuai hasil pemeriksaan.
7. Jika pengajuan telah memenuhi persyaratan, ubah status menjadi **Selesai**.

## 7. Mengunduh Surat PDF
Mahasiswa dapat mengunduh surat apabila pengajuan telah berstatus **Selesai**.
Langkah-langkah:
1. Login sebagai mahasiswa.
2. Buka dashboard.
3. Cari pengajuan dengan status **Selesai**.
4. Pilih opsi untuk mengunduh surat.
5. Sistem akan menghasilkan dokumen surat dalam format PDF.
6. Simpan dokumen PDF tersebut pada perangkat.

## 8. Logout

1. Buka menu akun.
2. Pilih **Logout**.
